## unalloc 0.3.2

The bundled demo now exercises every command without double counting.

- **`unalloc --version`** works, alongside `unalloc version`.
- **`unalloc reconcile --fixtures`** reconciles against bundled sample invoices. Anthropic ties out within the 1% tolerance; OpenAI billed $381.44 (8.6%) more than its costs endpoint reported. Pass `--invoice SOURCE=AMOUNT` to use your own figures.
- **Non-overlapping fixtures.** The LiteLLM fixture routes to Azure OpenAI, Vertex AI and Bedrock, which unalloc does not pull directly, so the default four-source report no longer counts the same spend twice. Amounts are unchanged: 73.5% of $66,630.38 is unattributed on `team`. See `src/unalloc/fixtures/README.md`.
- The quick start shows fallback attribution.

```bash
pip install --upgrade unalloc
unalloc report --fixtures --fallback cost_center
unalloc reconcile --fixtures
```

Real deployments still need source selection: if your gateway proxies OpenAI or Anthropic calls, choose sources with `--source`.
