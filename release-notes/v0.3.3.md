## unalloc 0.3.3: environment-lifetime accounting case study

This patch adds a **repository-only synthetic example**, not a production AWS integration.

- Allocates lifetime memory GB-seconds across concurrent requests independently per environment, without counting overlap twice.
- Preserves uncovered capacity as an explicit residual. It is called idle only for complete synthetic telemetry; otherwise it is unobserved.
- Demonstrates that exact reconciliation is insufficient evidence of correct attribution: the fixture totals 270 GB-s = 120 assigned + 150 residual. Removing one request changes the split to 105 + 165 while preserving the same total.
- Includes 43 focused tests, exact saved-output checks, and CI coverage.

All inputs are synthetic. Constant memory and equal sharing are model assumptions. No AWS account data, observed billing, CPU-cost model, prices, savings, or guaranteed idle lifetime is claimed.

The case study is in the [GitHub source tree](https://github.com/timurista/unalloc/tree/v0.3.3/case_studies/environment_lifetime) and GitHub source archives, **not** the PyPI wheel/sdist. Production CLI and adapters are unchanged; the package patch updates README metadata and version identity. The attached research paper is unchanged and does not report this new example.

From a checkout:
```sh
python3 -m case_studies.environment_lifetime
python3 -m unittest discover -s case_studies/environment_lifetime -t . -v
```
